LABORATORI 04 · REDUNDÀNCIA I DETECCIÓ

El receptor no té l’original.
Com pot sospitar d’un error?

Afegeix informació de control, altera la trama i comprova què pot detectar el receptor només amb allò que rep.

REPTE ADAPTAT

    Emissor

    Canviar les dades o el mètode crea una nova trama. Els bits de control es transmeten juntament amb les dades i també poden alterar-se.

    Trama enviada

    Dades en blanc; control amb vora violeta. La paritat és un únic bit per a tot el bloc.

    Trama rebuda · fes clic per invertir bits

    Receptor · només utilitza la trama rebuda

    Superar la comprovació no garanteix que les dades siguin les originals. Detectar un problema tampoc indica quin bit s’ha de corregir.

    Aquesta comparació és una ajuda del laboratori. El receptor no disposa de l’original.

    Regles i límits de cada mètode

    Paritat parella: s’afegeix un bit perquè el total d’uns sigui parell. Detecta un nombre senar d’inversions en la trama. Un nombre parell d’inversions pot passar desapercebut.

    Suma de comprovació: sumem els valors dels bytes i ens quedem el residu de dividir entre 256. El receptor recalcula la suma de les dades rebudes i la compara amb el byte de control rebut. Dos canvis que es compensin o un reordenament de bytes poden passar desapercebuts. És una suma didàctica, no un CRC ni una protecció criptogràfica.

    Sense protecció: el receptor no té cap prova d’integritat. Aquests mètodes no corregeixen els errors: caldria reenviar o utilitzar un codi corrector.
